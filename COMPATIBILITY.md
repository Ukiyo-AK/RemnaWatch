# Матрица установки и проверки (2026-10-20)

Матрица зафиксирована до разработки исправлений. «Целевая» означает контракт
preflight, а не сертификат проверки на чистой VM. Фактические результаты и
непроверенные сочетания перечисляются в TEST_REPORT_INSTALLATION.md.

| Конфигурация | Результат preflight / поведение |
|---|---|
| Debian 12/13, Ubuntu LTS 20.04/22.04/24.04/26.04; amd64/arm64; полноценный systemd | Расширенная целевая поддержка, Python 3.8+, venv без глобального pip; результаты проверок отдельно |
| Debian 11 | Runtime Python 3.9: 133 tests OK; установка зависимостей требует действующего подписанного репозитория. В проверенном чистом образе security mirror отдаёт 404, bootstrap безопасно отказывает |
| Python/venv/CA/iproute2/systemctl отсутствуют | При --apply или --install-deps установка недостающих distro packages; Python-free shell bootstrap |
| Конфликт APT, недоступные подписанные репозитории | Отдельный отказ dependency stage, без upgrade/remove/смены репозиториев и без удаления locks |
| Другие ОС/архитектуры | Отказ до записи, указание поддерживаемой платформы |
| Docker/LXC без systemd PID 1 | Отказ до записи; использовать systemd-хост |
| root / sudo | Установка после проверки владельцев и прав; без root доступен read-only отчёт |
| UFW active / inactive / absent; firewalld / nftables / внешний firewall | Обнаружение; по умолчанию только ручные правила; никогда auto-enable/reset |
| Caddy присутствует / отсутствует | Инвентаризация; существующие сайты не меняются |
| Docker Compose v1 / v2 / отсутствует | Инвентаризация; сбор существующих mounted-логов не требует Compose |
| s6 / Supervisor | Определение по реальному контейнеру и конфигурации логгера |
| Контейнер остановлен / несколько кандидатов / неизвестный логгер | Независимый отказ этапа истории с кодом и подсказкой |
| Лог существует и mounted / отсутствует / нечитаем | Подтверждение mount; отсутствие не исправляется созданием пустого файла |
| Порт probe свободен / совместимый probe / другой listener | Отдельный opt-in TLS listener / сохранить / отказ только этапа probe |
| DNS / HTTPS / часы / диск / зависимости неисправны | Проверяемая причина; TLS verification не отключается |
| Точный per-UUID rate limiting штатным Xray | Не подтверждён; API возвращает unsupported, общий tc не используется |

На тестовой ноде read-only подтверждены Ubuntu 24.04 amd64, активный агент,
Xray 26.7.28, s6 и существующий mount /var/log/xray. Позднее безопасным чтением
runtime release assignment подтверждена RemnaNode 3.2.0; начальное 0.0.0
исключено. `latest` и Docker image ID не являются версией. Отдельной arm64 /
Node 2.7.x / панели 2.7.4 среды у пользователя пока нет.

Изменения в соседнем ALTLINK-VPN уже присутствовали до этой работы. Их нельзя
считать частью проверенной поставки RemnaWatch без отдельного совместного теста.
